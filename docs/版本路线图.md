# promptLab 版本路线图

> 现状：v0.1.0（内测版）已上线 https://skills.zhecheng.fun，主站登录 + 数据隔离。
> 约定：每次功能交付自动 git commit；每个里程碑打 tag。

## v1.0.0 · 正式发布（当前目标）

**原则：不做大的新功能模块，仅小改动 + 完善发布。**

### 功能与改动

| 项 | 说明 |
|---|---|
| 内测问题修复 | 收集内测期反馈，逐项修复（UI、交互、稳定） |
| 选择加入 skill | 工匠（AI1）的回复支持选中段落，写入指定项目文件（比现在的整段写入更精细） |
| 多格式基础支持 | 项目文件支持上传（任意格式）+ 代码文件语法高亮（Monaco 语言识别） |
| 细节体验打磨 | 界面文字、对齐、反馈提示等小优化 |
| 桌面版（壳模式） | Electron 加载现有前端，连服务器后端；加桌面特性：多窗口、系统托盘、快捷键、本地文件拖入、系统通知。Windows 本地打包，macOS 用 GitHub Actions 云构建（.dmg） |
| 开源发布 | README、LICENSE（待定 MIT 或 Apache）、项目截图、使用文档、Release Notes；推送 GitHub 仓库并打 tag |

### 明确不做（延后）

- AI 质检 → v1.2
- 窗口化 → v1.3
- Excel 在线编辑（长期不做，CSV 只读预览见 v1.1）

## v1.1 · 能力增强（待细化）

- 多格式增强：CSV 只读预览、文件类型模板（新建时可选 py/js/md 等）
- 预期设定（质检前提）：用户为 skill 描述期望行为，作为质检的判断标准
- 内测/正式版收集的新反馈修复

## v1.2 · AI 调试（核心差异化）

- **质检意见**：质检 AI 监控用户与执行者的对话，按预期设定识别偏差，给出修改建议；用户手动采纳
- **自动调试**：质检 AI 自动与执行者对话 → 识别偏差 → 修改提示词/文档（需用户确认）→ 重新测试 → 循环
- 成本控制：质检按需开启、每会话限次，防止公共 API 被烧穿

## v1.3 · 窗口化

- 对话框、编辑器、文件列表支持拖动、缩放、浮动
- 布局状态持久化

## 长期（v2+）

- 桌面版本地模式（后端打包进应用，离线可用）
- 更多文件类型深度编辑
