# promptLab 使用文档（站内版 · 草稿）

> 此版本用于网站顶栏"使用文档"入口，内容比完整版精简，供你审阅编辑后再接入界面。

---

## promptLab 是什么

promptLab 是一个"造 AI 助手"的工作台。你只需要用自然语言描述想要一个什么样的 AI 助手，它就能帮你把提示词、规范文档写好，然后你直接和这个"造出来的 AI"对话、调试，直到满意。

## 快速开始（三步）

1. **新建项目**：左侧文件栏顶部点"+"，输入项目名（如"周报助手"）。
2. **写 Skill**：在中间编辑器打开 `SKILL.md` 直接写，或去右上"工匠台"让 AI 帮你写。
3. **测试**：在右下"测试台"和这个 AI 对话，看它表现如何；不满意就改文档再测。

## 界面

```
┌────────────┬───────────────────────┬─────────────┐
│            │                       │   工匠台     │
│  文件管理器  │       编辑器           ├─────────────┤
│            │                       │   测试台     │
└────────────┴───────────────────────┴─────────────┘
```

| 区域 | 作用 |
|---|---|
| 文件管理器（左） | 管理项目：新建项目、新建/重命名/删除文件、导出项目 |
| 编辑器（中） | 编辑 Skill 文档，支持 Markdown |
| 工匠台（右上） | 向 AI 描述需求，让它撰写提示词和文档；生成内容可整段或分段加入文件 |
| 测试台（右下） | 加载当前 Skill 文档，和你对话，模拟真实使用效果 |

## 常用操作

| 想做什么 | 怎么做 |
|---|---|
| 新建项目 | 左侧文件栏顶部"+" |
| 新建文件 | 左侧"文件"标题栏右侧"+" |
| 重命名 / 删除 / 导出 | 文件或项目行悬停后的小按钮 |
| 把工匠生成的内容存入文件 | 整段："写入 xxx"按钮；分段：鼠标悬停到某一段，点"加入 xxx" |
| 换 AI 模型 | 顶栏"模型设置" |

> 提示：发送消息时会自动保存当前编辑的文件；Skill 文档变化后测试台会自动开新会话。

## 模型设置

| 板块 | 用途 |
|---|---|
| 作者的 API（公共接口） | 网站作者提供的公共模型接口 |
| 工匠 | 帮你写文档的 AI |
| 执行者 | 测试台里和你对话的 AI |

每项可填 Base URL / API Key / 模型名。勾选"借用作者的 API"就不需要自己填 key。Key 保存后不回显，留空表示不修改。

## 常见问题

**改了文档，执行者还是老样子？** 修改后测试台会开新会话，请在新会话提问；确认文件已保存。

**执行者回答很奇怪？** 在 `SKILL.md` 里写清楚：身份、职责、语气、回复格式、禁忌。越具体越稳定。

**想让它知道我的背景信息？** 写在项目文档里（如 `notes.md`），新会话提问即可。

**提示未登录 / 401？** 登录态过期了，点"前往个人站登录"登录后回来刷新。
